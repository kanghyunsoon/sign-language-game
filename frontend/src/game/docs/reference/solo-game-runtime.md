# Solo Block Stacking Runtime

## 범위

`GameRuntime`은 `RemovalSystem`, `PhysicsWorld`, `GameRenderer`를 조합하는 솔로 게임 런타임이다. 인식기는 입력 포트를 통해서만 문자를 제출하며 Matter/Pixi 구현을 직접 알지 않는다. 솔로 게임은 Room WebSocket이나 WebRTC를 사용하지 않는다.

## 런타임 책임

- `RUNNING`일 때만 requestAnimationFrame 루프를 실행한다.
- 자동 타이머 생성은 끄고, 수달 종이에 표시된 목표를 인식했을 때만 블록을 생성한다.
- 종이 글자를 760ms 동안 확대하고, 확대가 끝난 위치와 크기에 Matter 블록을 생성한다.
- 물리 정착·이동 이벤트를 코어에 전달한다.
- 제거 효과가 끝난 후 Matter body를 제거하고 점수·콤보를 기록한다.
- 새로 정착한 블록의 보이는 상단이 결승선을 넘을 때만 종료한다.
- React에는 상태 전이만 발행하고 좌표는 Matter/Pixi에 유지한다.

## 목표 선택

1. 게임 시작 시 자음·모음 목록과 오답 가중치를 한 번 불러온다.
2. 서버 가중치 `w`는 `min(1.2, 1 + (w - 1) × 0.2)`로 완화한다.
3. 직전 글자는 후보에서 제외해 같은 문자가 연속으로 나오지 않게 한다.
4. 완화 가중치 합을 기준으로 weighted random을 수행한다.
5. API 실패나 잘못된 응답은 빈 가중치 맵으로 처리하고 모든 글자를 `1.0`으로 선택한다.

## 종이에서 물리 블록으로 전환

- 새 목표에는 80ms arming guard를 적용한다.
- 종이 글자 확대 중에는 Matter body를 만들지 않는다.
- 확대가 끝나면 종이 글자 중심과 같은 위치에 물리 블록을 만들고 전면 글자 레이어에서 렌더한다.
- 생성된 블록이 종이 영역을 벗어날 때까지 다음 목표를 표시하지 않는다.

## 인식 입력

- 목표가 없는 구간의 확정 인식은 버리고 입력 잠금을 초기화한다.
- 같은 확정 문자가 아직 release 대기 중이면 중복 제출하지 않는다.
- 다른 문자가 확정되면 이전 입력 잠금을 해제하고 새 문자를 판정한다.
- 숫자는 제외하고 지문자 자음·모음만 사용한다.

## 충돌체

- 기본 충돌 데이터는 `glyphCollisionDefaults.json`이다.
- 복합 모음은 하나의 큰 사각형이 아니라 여러 획 파트로 구성한다.
- 개발 환경에서 `/game/solo?collisionAudit=1`로 편집기를 연다.
- 브라우저 저장값은 임시 데이터다. 제품 기본값으로 확정하려면 내보낸 JSON을 기준 파일에 반영해야 한다.

## 종료와 기록

- 결승선 판정은 `LETTER_SETTLED` 이벤트가 발생한 블록만 대상으로 한다.
- 결과 기록은 `ceil(playTimeMs / 1000)`의 경과 초다.
- 결과 오버레이는 물리 글자보다 높은 레이어에 표시한다.
