# 솔로 지문자 테트리수 작업 상태 — 2026-07-29

관련 장애 원인과 해결책은 `solo-game-troubleshooting-2026-07-29.md`를 기준으로 한다.

## 완료 범위

- 수달 종이 중심 목표 방식과 인식 성공 시 중앙 낙하
- 종이 글자 확대와 Matter/Pixi 물리 블록의 단일 위치 hand-off
- 첫 목표 stale 인식 방지와 빠른 재인식 입력 잠금 개선
- 충돌체 편집기 및 글자별 획 단위 기본 충돌 JSON 적용
- 바닥 이탈·광범위 겹침 완화를 위한 물리 경계/충돌체 보정
- 새로 정착한 블록 기준 결승선 즉시 종료
- 결과 오버레이 전면 표시
- 경과 초 저장 및 랭킹 표시
- 오답 가중치 API 연동, 약한 가중치와 연속 중복 방지

## 게임 흐름

1. 게임 시작 시 지문자 목록과 오답 가중치를 한 번 읽는다.
2. 수달 종이에 직전 글자와 다른 목표를 표시한다.
3. 목표 인식 성공 시 종이 글자가 760ms 동안 최종 물리 크기로 확대된다.
4. 같은 위치에 물리 블록을 한 번만 만들고 자연 낙하시킨다.
5. 블록이 종이 영역을 벗어나면 다음 목표를 표시한다.
6. 새로 정착한 블록이 결승선을 넘으면 즉시 종료한다.
7. 경과 초를 저장하고 백엔드가 계산한 내 순위를 결과 화면에 표시한다.

## 운영 API

- 결과: `POST /api/solo-results?userId={userId}` body `{score: elapsedSeconds}`
- 랭킹: `GET /api/rankings?userId={userId}&gameType=TETRIS_SOLO`
- 가중치: `GET /api/wrong-answers/tetris-weights`
- 자음 매핑: `GET /api/signs?category=CONSONANT`
- 모음 매핑: `GET /api/signs?category=VOWEL`

솔로 전용 원격 session start API는 호출하지 않는다.

## 가중치 정책

- 서버 가중치 증가분의 20%만 반영한다.
- 유효 가중치는 최대 `1.2`다.
- 같은 문자는 연속 선택하지 않는다.
- API나 응답 계약 실패 시 모두 `1.0`으로 진행한다.

## 충돌 편집

- 개발 전용 URL: `/game/solo?collisionAudit=1`
- 기준 파일: `frontend/src/game/block-stacking/glyphs/glyphCollisionDefaults.json`
- 브라우저 저장은 편집 중 복구용이다. 배포 기본값은 기준 JSON 파일이다.

## 남은 외부 확인

`TETRIS_SOLO` 랭킹이 낮은 `score`를 더 높은 순위로 계산하는지는 백엔드 정책이다. 프런트는 경과 초 제출과 `me.rank` 표시만 담당한다.

## 검증 결과

- 솔로 런타임·Matter 물리·가중치 API·결과 API·결과 매퍼·세션·게임 모듈 관련 테스트: 7개 파일, 52개 통과

- 전체 테스트의 남은 5개는 이번 솔로 변경 목록 밖의 기존 계약 불일치다.
  - 학습 데이터 설명을 정확히 2줄로 제한하는 테스트 2개
  - 제거된 사용자 등록 과정을 전제로 하는 인식 세션 테스트 2개
  - 1:1 봇 대전의 6초 결승선 arm/정착 지속 조건을 반영하지 않은 테스트 1개

## 이번 안정화 반영

### 블록 크기와 물리

- 솔로 글자 표시 크기와 물리 충돌 크기의 공통 기준을 `220px`로 통일했다.
- 중력과 최대 낙하 속도는 각각 `0.32`, `4.1`로 유지하면서 마찰과 공기 저항을 낮춰 블록이 자연스럽게 굴러가도록 했다.
- 일반 블록의 정착 판정은 4초로 늘리고 정착 후 강제 고정은 사용하지 않는다.
- 충돌 충격으로 기존 더미가 과도하게 흩어지지 않도록 반발력은 `0.035`로 낮췄다.

### 다음 목표와 결승선

- 종이에서 방출된 블록이 높은 더미 위에 일찍 정착한 경우에도 다음 목표가 정상적으로 표시된다.
- 결승선을 넘은 블록은 완전히 정착했으면 즉시 종료한다.
- 아직 정착 이벤트가 없더라도 결승선 위에서 320ms 동안 거의 움직이지 않으면 더 떨어질 가능성이 없는 것으로 보고 결과 화면을 표시한다.
- 낙하 또는 회전 중인 블록은 위 조건에 포함하지 않아 조기 종료를 막는다.

### 결과 화면과 저장

- 결과 화면에는 `2:07`과 같은 분:초 기록만 표시한다.
- 백엔드에는 기존 계약대로 정수 초를 `score`로 보낸다.
- 결과 카드에는 `다시 하기`와 `홈으로`를 같은 폭으로 제공한다.
- 결과 오버레이는 물리 글자보다 위에 렌더해 쌓인 글자가 결과 내용을 가리지 않는다.

### 카메라와 MediaPipe

- `object-fit`으로 잘린 원본 영상 영역을 역산해 실제 카메라 프레임 안에 있는 랜드마크만 그린다.
- 손의 21개 랜드마크가 보이는 영상 범위 안에 있을 때만 AI 인식 입력으로 전달한다.
- 카메라 프레임 밖에서 손을 움직여도 화면 안의 관절선이나 현재 인식 문자가 갱신되지 않는다.

### 시간·배경·힌트 수달 표시

- 플레이 시간은 렌더링·카메라·AI 인식 이벤트와 분리해 실제 경과 시간을 누적한다. 따라서 인식 입력이 없거나 한 프레임이 늦어도 초 단위 시간이 빠지지 않는다.
- 기본 Pixi 배경 장식은 끄고, 솔로 화면의 DOM 배경만 사용한다. 구름 이동, 해/빛나는 초승달 전환, 별·반딧불·언덕 움직임을 하나의 배경 계층에서 관리해 이중 풍경이 겹치지 않는다.
- 7초 이상 목표를 맞히지 못했을 때 등장하는 힌트 수달의 종이 안쪽에는 고정된 `66 × 66px` 안전영역만 사용한다. 지문자 안내 그림은 `58px`로 제한하고 `overflow: hidden`으로 잘라, 세로로 긴 손 모양도 종이 또는 수달 캔버스 밖으로 나가지 않는다.

## 시작 화면·상단 UI 정리 (2026-07-31)

- 시작 오버레이 중앙에 있던 `프링글수` 타이틀 이미지는 상단 뒤로가기 버튼 오른쪽의 제목 영역으로 이동했다.
- 상단의 텍스트 제목(`SOLO · BLOCK STACK`, `지문자 테트리수`)과 일시정지·새로고침 버튼은 제거했다. 게임 재시작은 결과 화면의 `다시 하기` 흐름으로 유지한다.
- 원본 타이틀 PNG에는 큰 투명 여백이 있으므로 `.solo-header-logo`가 고정 크롭 영역을 제공하고, 내부 이미지를 음수 오프셋으로 배치한다. 이미지 자체를 다시 가공하지 않는다.
- 시작 버튼은 단상·내 순위 카드와 겹치지 않도록 오버레이 기준 `top: 84%`에 배치한다.
- 솔로 보드와 카메라 카드는 같은 워크스페이스 행의 전체 높이를 공유한다. 카메라 헤더 행을 `24px`으로 제한해 실제 영상 뷰포트의 위·아래 기준선을 게임판 캔버스와 맞춘다.
- 뒤로가기 버튼은 로고의 아이보리·베이지·브라운 팔레트(`#fffaf0`, `#eadbc7`, `#765a43`)를 사용한다.

### 확인 항목

1. 16:9 고정 배율에서 상단 로고가 잘리지 않고 뒤로가기 버튼 오른쪽에 표시되는지 확인한다.
2. 상단 우측에 일시정지·새로고침 제어가 남아 있지 않은지 확인한다.
3. 게임판과 카메라 영상 영역의 상단·하단 기준선이 나란히 맞는지 확인한다.

## 게임 카테고리 카드 정리 (2026-07-31)

- `/game`의 `BLOCK_STACK` 카드 제목은 일반 텍스트 대신 솔로 시작 화면과 같은 `solo-start-title.png`의 `프링글수` 로고를 사용한다.
- 카드는 로고 원본을 수정하지 않는다. `144px × 54px` 크롭 래퍼와 내부 이미지의 음수 오프셋(`195px` 너비)을 사용해 투명 여백을 제거한다.
- 로고 크롭 영역은 카드 우측 상단의 `SOLO · 1 VS 1` 배지와 겹치지 않도록 줄였고, 왼쪽 아이콘과 설명 본문 축에 맞췄다.
- 안내 문구는 블록을 쌓는 솔로 기록과 1:1 승부 흐름을 함께 설명하도록 갱신했다.

### 확인 항목

1. `/game`의 지문자 테트리스 카드에서 로고·배지·설명 사이에 겹침이 없는지 확인한다.
2. 카드 폭이 바뀌어도 로고가 컨테이너 밖으로 나오지 않는지 확인한다.
3. 다른 화면의 솔로 시작 로고 크롭에는 영향을 주지 않는지 확인한다.
