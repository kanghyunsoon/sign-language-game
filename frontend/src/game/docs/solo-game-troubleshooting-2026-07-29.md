# 솔로 지문자 테트리수 트러블슈팅 — 2026-07-29

## 첫 글자가 인식 직후 바로 터짐

**원인:** 게임 시작 전에 발생한 인식 확정 이벤트가 새 목표가 그려진 프레임에 전달됐다.

**조치:** 새 종이 목표마다 80ms arming guard를 두고 이 시간의 확정 입력은 소비하지 않는다. 목표가 없는 구간에는 인식 gate와 입력 잠금을 초기화한다.

## 종이 앞에서 커진 글자가 뒤에서 다시 나타나거나 순간 이동함

**원인:** 종이 글자 애니메이션과 Matter/Pixi 물리 글자를 동시에 생성해 서로 다른 레이어와 시작 좌표에서 두 사본이 보였다.

**조치:** 확대가 끝날 때까지 물리 body를 생성하지 않는다. 완료 시 종이 글자의 최종 중심과 같은 위치에 한 번만 body를 만들고 전면 글자 레이어에서 렌더한다. 물리 글자가 종이 영역을 빠져나갈 때까지 다음 목표도 숨긴다.

## 글자 충돌체가 획과 어긋나거나 복합 모음의 빈 공간까지 막힘

**원인:** 폰트 외곽 전체를 하나의 큰 충돌 사각형으로 근사했고 브라우저 편집 결과가 제품 기본 JSON에 반영되지 않은 경우가 있었다.

**조치:** `glyphCollisionDefaults.json`을 단일 기준으로 삼고 획별 파트를 사용한다. `/game/solo?collisionAudit=1`에서 최종 JSON을 확인한 뒤 파일에 반영한다. `ㅢ`, `ㅟ`처럼 분리된 획은 별도 파트로 유지한다.

## 블록이 바닥 밖으로 빠지거나 겹침

**원인:** 글자 충돌 패딩, 바닥 경계와 표시 크기의 기준이 서로 달랐다.

**조치:** 충돌체를 획에 가깝게 축소하고 최소 패딩만 유지했다. 바닥 경계를 보드 내부 기준으로 고정하고 충돌 감사 테스트를 추가했다.

## 결승선에 닿기 전에 끝나거나 한 블록 늦게 끝남

**원인:** 매 프레임의 모든 body 위치로 판정하면 낙하/반동 중인 글자도 종료를 만들고, 다음 생성 시점에만 검사하면 한 글자 늦었다.

**조치:** 해당 프레임에 `LETTER_SETTLED`가 발생한 블록만 검사한다. 그 블록의 보이는 상단이 결승선을 넘으면 같은 프레임에 종료한다.

## 인식한 글자가 바뀌었는데 다시 시도되지 않음

**원인:** 이전 확정 문자의 hand-release 잠금이 다음 목표나 다른 문자까지 남았다.

**조치:** 목표가 바뀌거나 다른 문자가 확정되면 이전 입력 잠금을 즉시 해제한다. 같은 문자의 중복 확정만 차단한다.

## 경과 시간 랭킹 방향

프런트는 `POST /solo-results`에 올림한 경과 초를 보내고 `GET /rankings?...gameType=TETRIS_SOLO`의 `me.rank`를 표시한다. 낮은 기록 우선 정렬은 백엔드 책임이다. 운영 랭킹이 높은 점수 우선이면 백엔드의 TETRIS_SOLO 정책을 MIN/ASC로 수정해야 한다.

## 오답 가중치가 게임 다양성을 훼손함

서버 가중치를 그대로 쓰지 않고 증가분의 20%만 반영하며 최댓값을 `1.2`로 제한한다. 직전 문자는 후보에서 완전히 제외한다. API 실패 시 균등 가중치로 진행한다.

## 높은 더미에서 다음 종이 글자가 나오지 않음

**증상:** 방금 떨어진 글자가 결승선 아래의 안전한 위치에 멈췄는데도 다음 목표가 표시되지 않았다.

**원인:** 다음 목표 대기 조건이 방출 글자의 `y` 위치만 확인했다. 글자 크기가 커지고 더미가 높아지면서 글자가 종이 아래 임계값을 통과하기 전에 물리적으로 정착할 수 있었고, 이 경우 대기가 영구히 풀리지 않았다.

**조치:** 방출 글자가 아직 움직이는 동안에만 위치 임계값을 기다린다. 이미 정착한 글자는 안전선 판정과 별개로 다음 목표를 즉시 큐에 넣는다. 220px 글자가 높은 위치에서 정착하는 회귀 테스트를 추가했다.

## 결승선에 멈춘 뒤 결과 화면이 늦게 표시됨

**증상:** 블록이 결승선을 넘고 사실상 멈췄는데 일반 정착 시간 4초를 모두 기다렸다.

**원인:** 자연스럽게 굴러가는 시간을 늘리기 위해 정착 시간을 길게 조정한 값이 게임 종료 판정에도 그대로 적용됐다.

**조치:** 일반 정착과 결승선 종료를 분리했다. 결승선 위 블록이 선형 속도 `0.05`, 각속도 `0.005` 이하로 320ms 유지되면 즉시 종료한다. 속도나 회전이 다시 커지면 누적 시간을 초기화한다.

## 충돌 시 기존 블록 더미가 지나치게 무너짐

**원인:** 220px로 커진 블록의 질량과 낙하 충격에 비해 반발력과 낙하 에너지가 높았다.

**조치:** 반발력을 `0.035`, 중력을 `0.32`, 최대 낙하 속도를 `4.1`로 조정했다. 마찰은 낮게 유지해 위에 불안정하게 놓인 블록은 굴러가되 바닥 전체로 튀어 흩어지는 현상은 줄였다.

## 카메라에 보이지 않는 손이 MediaPipe에 잡힘

**증상:** 원본 웹캠 영상에는 손이 있지만 `object-fit`으로 잘린 카메라 카드에는 손이 보이지 않는데도 관절선이나 인식 결과가 갱신됐다.

**원인:** MediaPipe 좌표를 전체 원본 영상 기준으로 캔버스에 투영했고, 실제 화면에 노출되는 원본 crop 범위를 판정하지 않았다.

**조치:** 카메라 컨테이너와 원본 영상 비율로 보이는 source crop을 계산한다. 손의 21개 랜드마크가 모두 crop 내부에 있는 경우에만 캔버스 렌더링과 AI 판정으로 전달한다.

## 결과 화면보다 물리 글자가 앞에 보임

**원인:** 물리 글자 전용 전면 레이어의 쌓임 순서가 결과 오버레이보다 높았다.

**조치:** 게임 종료 오버레이를 최상위 결과 계층으로 올리고, 종료 상태에서는 입력과 물리 화면보다 결과 카드가 우선 보이게 했다.
