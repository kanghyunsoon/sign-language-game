# Block stacking

블록쌓기 솔로, 봇 연습, 실시간 1:1과 공통 물리·렌더·점수 엔진을 소유한다. 방·인증·통신 구현은 상위 `contracts`, `match`, `media`, `recognition` 경계를 통해 사용한다.

## 2026-07-29 솔로 모드 기준

- 자동 생성 타이머를 사용하지 않는다. 수달 종이의 지문자를 인식하면 종이 위 글자가 확대된 뒤 같은 위치에서 Matter 물리 블록으로 전환되어 중앙 낙하한다.
- 새 목표는 이전 물리 블록이 종이 영역을 벗어난 뒤에만 표시한다. 첫 목표에는 80ms 입력 준비 시간을 두어 이전 인식 결과가 즉시 소비되는 현상을 막는다.
- 글자는 마지막 선택 글자와 연속 중복되지 않는다.
- 게임 시작 시 오답 가중치를 한 번 불러오되 최대 `1.2` 범위로 약하게 완화한다. API 실패 시 전 글자 `1.0`으로 계속 진행한다.
- 충돌체는 글자 전체 사각형이 아니라 획 단위 파트로 구성한다. 개발 환경의 `/game/solo?collisionAudit=1`에서 글자별 충돌체를 편집·저장·내보낼 수 있다.
- 종료 판정은 새로 정착한 블록의 보이는 상단이 결승선을 넘는 순간에만 수행한다.
- 완료 기록은 점수가 아니라 올림 처리한 경과 초를 `POST /solo-results`로 전송한다.

## 2026-08-02 프링글수 1:1 기준

- 로비에는 게임 종류가 일치하고 빈자리가 있는 `WAITING` 방만 표시한다. 종료 직후 두 참가자가 남은 `2/2` 방은 재대결 대기 상태여도 목록에서 숨긴다.
- create/join/leave 요청은 순서를 보장해 뒤로가기 직후 재입장 상태가 되거나 이전 방 leave 전에 새 방을 생성하는 경쟁을 막는다.
- 1:1은 두 독립 게임판과 하나의 공유 2D 배경을 사용한다. 결승선과 실제 승리 판정은 모두 게임판 높이의 `1 / 6`이다.
- 결과 화면에서 `다시 하기`와 `같은 방으로`는 대기실, `게임방 목록`은 leave 후 `/game/battle`로 이동한다.
- 방 제목·방장 닉네임·출제 범위의 서버 공유 범위는 배포 Swagger 필드에 제한된다. 현재 브라우저에서 생성한 방은 gateway 메모리로 보완하지만 다른 브라우저까지 영구 전파되는 값은 아니다.

세부 기준:

## 2026-08-02 장시간 게임 성능 기준

- 솔로·1:1의 실제 글자는 DOM 마스크로만 표시하며, 화면에 보이지 않는 Pixi 글자 뷰를 중복 생성하지 않는다.
- 낙하 중인 글자만 GPU 합성 힌트를 사용하고 정착한 글자는 합성 레이어를 반환한다.
- 움직임과 효과가 없는 로컬·상대 보드는 10FPS로 순회 비용을 낮추고, 새 낙하가 시작되면 즉시 고주기 갱신으로 복귀한다.
- 상대 제거 이력과 P2P 처리 명령 이력은 각각 최근 128개와 256개로 제한한다.
- 제한된 글자 집합의 래스터 캐시는 유지하고, 모든 캐시를 주기적으로 삭제하지 않는다.

상세 원인·해결·검증은 `../docs/game-troubleshooting.md`의 「1:1 누적 성능」 절을 기준으로 한다.

### 2026-08-03 상대 보드 보간 후속 기준

- 낙하 중인 상대 글자는 30Hz 변환 전송과 60Hz 화면 샘플링을 사용하고,
  정착 보드는 10FPS 저비용 경로를 유지한다.
- 보간 버퍼는 FALLING 상태만 최대 70ms까지 제한적으로 예측해 짧은 전송 공백을 완화한다.
- 전체 스냅샷은 5초마다 전송한다. 정착·제거 등 구조 변경은 즉시 스냅샷을 전송해
  권위 상태 복구를 보장한다.
- 솔로와 1:1 플레이 헤더는 타이틀 장식이 뒤로가기 버튼의 보이는 클릭 범위를 가리지 않도록
  버튼 레이어를 분리한다.
