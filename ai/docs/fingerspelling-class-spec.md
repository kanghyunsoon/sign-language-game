# 지문자 인식 범위 및 판정 기준

## 문서 상태

- 버전: 0.1.0
- 상태: 초안
- 기준 수형 검수: 한국수어 사용 경험자 또는 전문가 검수 필요
- 클래스 출처: [국립국어원 한국수어사전](https://sldict.korean.go.kr/)

이 문서는 데이터 수집, 라벨링, 모델 학습 및 실시간 추론에서 공통으로 사용하는 지문자 인식 기준을 정의한다.

## 인식 범위

한국 지문자 기본 세트인 자음 14개와 모음 17개를 직접 인식한다. 숫자는 한 자리 지숫자 `0`부터 `9`까지 직접 인식한다. `NONE`과 `TRANSITION`을 포함한 전체 클래스 카탈로그는 43개다.

지문자와 숫자에서 유사한 손 모양이 발생할 수 있으므로 인식 모드를 분리한다.

- `jamo`: 자음 14개, 모음 17개, 상태 2개
- `digit`: 숫자 10개, 상태 2개

서비스는 입력 목적에 따라 모드를 지정하고, 모델은 해당 모드의 활성 클래스만 분류한다.

## 상태 정의

### NONE

현재 프레임에 유효한 목표 지문자가 없는 상태다.

- 손이 화면에 없다.
- 손은 있지만 지문자 자세가 아니다.
- 손이 심하게 가려져 있다.
- 모든 클래스의 신뢰도가 기준 미만이다.

좌표 모델 학습에는 손이 검출된 비지문자 자세를 사용한다. 손이 없는 경우는 랜드마크 감지 단계에서 규칙 기반으로 `NONE` 처리한다.

### TRANSITION

한 지문자에서 다른 지문자로 이동 중인 상태다.

- 손가락 관절 형태 또는 손바닥 방향이 변경 중이다.
- 어떤 클래스도 안정적으로 유지되지 않는다.
- 직전 확정 클래스와 새로운 후보 클래스 사이의 구간이다.

수집 시 라벨 전환 전후 300ms 구간은 `TRANSITION` 후보로 관리한다.

## 정답 자세 기준

각 클래스는 국립국어원 자료의 해당 지문자 또는 지숫자 사진과 영상을 기준 자세로 사용한다.

- 한 손의 21개 랜드마크가 정상 검출된다.
- 손가락의 펴짐, 굽힘 및 접촉 관계가 기준 자세와 일치한다.
- 손바닥과 손등의 방향이 기준 자세와 일치한다.
- 손목과 손가락의 상대 위치가 기준 자세와 일치한다.
- 정적 클래스에서 불필요한 손가락 움직임이 없다.
- 동일 동작 중 우세손이 변경되지 않는다.
- 왼손 사용자는 좌우 반전 정규화 후 동일 기준을 적용한다.

## 잘못된 자세 기준

- 기준과 다른 손가락이 펴지거나 접혀 있다.
- 필요한 손가락 접촉이 없거나 불필요한 접촉이 있다.
- 손바닥 방향이 반대이거나 옆으로 과도하게 회전했다.
- 손가락 또는 손목이 화면 밖으로 벗어났다.
- 손가락이 겹치거나 다른 물체로 핵심 랜드마크가 가려졌다.
- 자세를 만들거나 해제하는 중이다.
- 정적 자세에서 손가락 움직임이 계속 발생한다.
- MediaPipe 손 검출 신뢰도가 설정 기준 미만이다.

`ㅓ`, `ㅔ`, `ㅕ`, `ㅖ`는 방향 차이를 주요 판정 요소로 기록하고 별도의 혼동 평가를 수행한다.

## 시간 판정 기준

| 항목 | 기본값 | 의미 |
| --- | ---: | --- |
| 수집 최소 유지시간 | 2,000ms | 유효 학습 구간의 최소 시간 |
| 후보 시작시간 | 300ms | 동일 클래스가 후보가 되기 위한 시간 |
| 인식 확정시간 | 800ms | 후보 문자를 인식 결과로 확정하는 시간 |
| 성공 유지시간 | 2,000ms | 충분히 유지한 동작으로 판정하는 시간 |
| 일시적 실패 허용시간 | 200ms | 순간적인 손 가림이나 오인식 허용시간 |
| 동작 종료시간 | 300ms | 다른 클래스 또는 NONE이 지속되는 종료 기준 |
| 동일 문자 재입력 간격 | 300ms | 같은 문자를 다시 입력하기 위한 해제 시간 |

### 시작

- 클래스 신뢰도 `0.80` 이상이 300ms 동안 유지되면 후보를 시작한다.
- 시작 시각은 최초로 조건을 만족하기 시작한 프레임의 타임스탬프다.

### 유지

- 유지 신뢰도 기준은 `0.60` 이상이다.
- 200ms 이하의 검출 실패는 동일 동작으로 간주한다.
- 허용시간 안에 복귀하면 유지시간을 연속으로 계산한다.

### 종료

- 다른 클래스 또는 `NONE`이 300ms를 초과하면 동작을 종료한다.
- 종료 시각은 마지막으로 유효했던 프레임의 타임스탬프다.
- 종료 후 상태는 `TRANSITION`으로 변경한다.

## 학습 데이터 유효 조건

- 한 구간이 2초 이상 유지된다.
- 전체 프레임의 90% 이상에서 손이 검출된다.
- 동일 구간에서 참가자와 우세손이 변경되지 않는다.
- 구간 시작과 종료의 전환 프레임이 제거되어 있다.
- 클래스 ID와 기준 자세가 일치한다.
- 참가자, 세션, 촬영 각도와 조명 정보가 기록되어 있다.
