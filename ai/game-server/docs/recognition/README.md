# Korean fingerspelling AI documentation

This directory is the canonical home for model training and evaluation documentation.

- [Training handoff](./training-handoff.md): data requirements, GPU reproducibility, current checkpoint, and the next safe learning unit.
- [Model evaluation](./model-evaluation.md): experiment-by-experiment metrics, class failures, regressions, and deployment decisions.
- [Raw evaluation](./model-evaluation.json): machine-readable evaluation record.

Frontend game documentation deliberately contains only camera, recognition-runtime, and UX behavior. It must not be used as the source of truth for model quality or training operations.
