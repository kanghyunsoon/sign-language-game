# 지문자 모델 학습·튜닝 기록

손의 방향에 따라 섞이는 자모를 확인하고, 입력 데이터와 학습 조건을 바꿔 모델을 조정했습니다. 스크립트 작성과 튜닝에는 AI를 사용했고, 저는 인식 결과와 실험 기록을 비교하며 다음에 바꿀 조건을 정했습니다.

[프로젝트 소개로 돌아가기](../README.md)

## 1. 화면상 모양이 비슷한 자모를 구분하기 어려웠습니다

기존 2D 입력은 손가락의 화면상 방향과 관절 각도를 사용했습니다. 손가락이 앞뒤로 향하거나 손바닥을 돌렸을 때 생기는 차이가 입력에 충분히 남지 않았습니다. 분류기를 바꾼 실험에서도 혼동이 남아 입력부터 살펴봤습니다.

MediaPipe는 x·y뿐 아니라 z 좌표도 제공하고 있었습니다. 이 좌표로 손가락 방향, 관절 각도와 손바닥 방향을 계산하도록 입력 스크립트를 수정했습니다. 사라진 깊이를 2D 데이터에서 복원한 것이 아니라, 이미 전달되던 z 좌표를 사용한 것입니다.

| 입력에 담은 정보 | 값의 개수 |
| --- | ---: |
| 손가락 뼈 20개의 x·y·z 방향 | 60 |
| 관절 각도 | 15 |
| 손바닥이 향하는 방향 | 3 |
| 합계 | 78 |

이 입력으로 학습한 3D LSTM은 평가 시퀀스 955개에서 93.3%를 기록했습니다. 이 단계와 아래 앙상블 단계는 평가 데이터가 달라 두 정확도의 차이를 개선율로 계산하지 않았습니다.

## 2. 2D와 3D 모델의 결과를 합쳤습니다

3D 모델은 방향을 구분하는 데 도움이 됐지만 학습 데이터가 2D 모델보다 적었습니다. 자모별 결과를 비교한 뒤 한쪽 모델을 버리기보다 두 모델의 예측을 합치는 실험을 진행했습니다.

같은 손 좌표에서 2D 입력 55개와 3D 입력 78개를 각각 만들고, 두 LSTM이 내놓은 자모별 확률을 절반씩 평균했습니다. 자주 섞이는 자모에는 구분을 더 학습하도록 손실 함수에 조건을 추가했습니다.

| 실험 | 내부 평가 정확도 | 판단 |
| --- | ---: | --- |
| 두 모델의 확률 평균 | 98.1% | 자모별 혼동을 이어서 확인 |
| 혼동 자모 학습 조건 조정 | 98.68% | 직접 사용하며 손목 각도 문제 확인 |
| 회전 증강 적용 | 98.42% | 회전 입력 평가 후 배포 모델로 선택 |

이 표는 평가 시퀀스 1,900개를 사용한 실험 기록입니다. 전체 정확도뿐 아니라 어떤 자모가 다른 자모로 분류되는지도 확인했습니다. 조건을 강하게 주자 다른 자모의 결과가 나빠진 실험은 적용하지 않았습니다.

## 3. 테스트에서는 맞던 손 모양이 직접 사용할 때는 인식되지 않았습니다

직접 사용하면서 `ㅡ`가 잘 인식되지 않는 경우를 확인했습니다. 기존 평가에서는 해당 자모를 맞히고 있어 확정 임계값만 낮추는 것으로는 원인을 설명하기 어려웠습니다.

손목 각도를 바꾸며 확인한 뒤 학습 입력에도 회전을 추가했습니다. 학습 샘플 일부를 회전시키고, 평가 입력을 ±10°와 ±20°로 돌려 결과를 따로 비교했습니다. 이 회전 평가는 촬영 영상을 새로 수집한 테스트가 아니라 좌표 입력을 변형한 테스트입니다.

회전 증강 후 전체 정확도는 98.68%에서 98.42%로 0.26%p 내려갔습니다. 대신 ±20° 회전 입력에서도 `ㅡ` 재현율 1.00을 확인하고 모델을 선택했습니다. 이 결과만으로 모든 사용자의 손목 각도 문제를 해결했다고 보지는 않습니다.

## 4. 모델의 예측과 게임 입력을 나눴습니다

모델이 자모를 한 번 맞혔다고 곧바로 게임 입력으로 처리하지 않았습니다. AI 서버는 후보와 확률을 반환하고, 브라우저가 일정 시간의 예측을 모아 입력을 확정합니다. 확정 이후에는 손 모양을 해제하거나 다음 입력 조건을 만족해야 다시 입력할 수 있습니다.

경쟁 모드에는 내부 평가에서 정밀도 90%, 확정률 85% 기준을 통과한 27개 자모를 사용했습니다. 제외한 자모는 `ㅓ·ㅗ·ㅜ·ㅡ`입니다. 회전 평가에서 `ㅡ`를 맞혔더라도 다른 자모를 `ㅡ`로 잘못 받아들이는 경우까지 사라진 것은 아니므로 출제 기준은 별도로 적용했습니다.

## 평가 조건

최종 모델의 정확도 98.42%는 같은 촬영 영상의 앞 70%와 뒤 30%를 나눠 학습·평가한 결과입니다. 평가 시퀀스는 1,900개이고, 학습에 참여하지 않은 사람을 대상으로 한 독립 평가는 아닙니다.

처음 사용하는 사람이나 다른 조명·카메라에서도 같은 성능이 나오는지는 추가 검증이 필요합니다. 이 저장소에서는 내부 실험 결과와 평가 범위를 함께 남겼습니다.
