GameRooms 로비 메타데이터 수동 테스트 — roomTitle / hostName / symbolRange

방 생성 시 roomTitle/symbolRange를 서버에 보내고, 방장 닉네임(hostName)은 서버가 로그인한 사용자로 조회해 채우는지, 로비 SSE 목록과 재연결/방장 위임 후에도 정보가 유지·갱신되는지 확인하는 도구입니다.

사용 전 확인사항 (CORS / 서버 실행)
  1. ./gradlew bootRun으로 백엔드를 기동합니다 (기본 http://localhost:8080).
  2. 이 HTML을 file://로 직접 열지 말고, 정적 서버로 서빙하세요. 예: 이 폴더에서 python -m http.server 5500 또는 VSCode Live Server.
  3. CORS 검사가 cors.allowed-origins(env CORS_ALLOWED_ORIGINS)를 사용합니다. 백엔드 기동 전에 CORS_ALLOWED_ORIGINS=http://localhost:5500(이 페이지를 서빙하는 origin)를 설정해야 합니다.
  4. 기본 흐름: A/B 모두 회원가입 → 로그인 → 로비 SSE 구독. A가 방 제목/기호 범위/게임 종류를 정해 방 생성 → B의 로비 목록에 title/hostName/symbolRange가 즉시 나타나는지 확인. 이어서 B의 로비 SSE를 재연결해도 같은 정보가 유지되는지, A가 방을 나가 방장이 위임되면 hostName이 새 방장 닉네임으로 갱신되는지 확인합니다.
